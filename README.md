# 🌱 Simple Greenhouse Monitoring & Control System

An IoT-based greenhouse monitoring system developed using ESP32 to monitor environmental conditions in real time. The system collects temperature, humidity, soil moisture, and light intensity data and displays the readings through the Blynk mobile application.

This project was developed collaboratively by a six-member team as an Embedded Systems Mini Project at Uva Wellassa University.

## 🎯 Project Objectives

- Monitor greenhouse environmental conditions in real time.
- Measure temperature and humidity using a DHT11 sensor.
- Monitor soil moisture using a capacitive soil moisture sensor.
- Measure light intensity using an LDR sensor.
- Provide visual environmental indicators using LEDs.
- Display sensor readings through the Blynk mobile application.

## ✨ Key Features

- Real-time environmental monitoring.
- Temperature and humidity measurement.
- Soil moisture monitoring.
- Light intensity monitoring.
- LED-based environmental condition indicators.
- Wi-Fi connectivity using ESP32.
- Remote monitoring through the Blynk application.
